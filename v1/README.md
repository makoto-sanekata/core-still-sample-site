# 見本 v1（初版）：お客さまの流れを、一通り触れる見本

株式会社CORE STILL（代表 古川 巨久さん）に、新しいお客さまが来てから翌朝のレポートが届くまでの流れと、トレーナー側の画面・管理表を、スマホで一通り触れるようにした最初の見本です。公開は古川さんの了解を得ています。

- 公開中の見本（v1）：https://cs-sample-e3bc37aa.makoto-net1210.workers.dev
- 作り直した版（v2）は、リポジトリの上の階層（`../public/`）にあります。

## v1 と v2 のちがい

| | v1（このフォルダ・7ページ） | v2（上の階層・10ページ） |
|---|---|---|
| 軸 | 予約までの流れを一通り触る。ノリさん向けの見方・次へ・感想の欄つき | 最初の画面に、来た人の温度ごとの入口を3つ。流れを8段に |
| 見た目 | 自前の簡素なCSS（配色・書体だけ本物に合わせた） | 本物のサイトのCSS・JSをそのまま使う |

## 見本であること

- 予約、支払い、自動のお知らせ、LINE配信、レポートの送信は動きません。画面と文面の見本です。
- お客さまの名前と数字は、すべて架空です。料金は〇〇,〇〇〇円の仮表示です。
- 入力欄（`<form>`・`<input>`）、外部のスクリプト・フォント・アクセス解析は置いていません。
- 全ページに「見本」の帯と noindex（検索に出さない）が付いています。

## 構成

- `site/public/` … 公開するファイル（静的HTML・共通CSS・`_headers`・`robots.txt`）
- `fixtures/demo-data.json` … 共通のダミーデータ（名前・日時・文面の元。すべて架空）
- `site/check_site.py` … 見本の検査（帯・noindex・外部なし・ダミーデータとの一致・リンク切れなど13項目）
- `site/selftest_check_site.py` … 検査をわざと壊して（68通り）、ちゃんと不合格になるかを確かめる

## 確かめ方

```bash
python3 v1/site/check_site.py
python3 v1/site/selftest_check_site.py
```

外部のライブラリは使っていません（Python 3 の標準ライブラリだけ）。
